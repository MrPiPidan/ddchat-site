DDchat 隐私政策

最后更新日期：2026 年 8 月 23 日

DDchat（以下简称“本应用”）非常重视您的隐私。本隐私政策说明了本应用如何收集、使用和保护您的信息。

1. 信息收集

本应用不会建立账号、投放广告或使用分析 SDK 收集您的个人信息。为提供您主动使用的 AI 对话与联网搜索功能，相关内容会直接发送给您选择的第三方服务商：

  • API 密钥：您配置的 API 服务商地址和密钥仅存储在您的设备本地，不会上传到任何服务器。
  • 对话内容：您与 AI 助手的所有对话记录仅保存在您的设备本地存储中。
  • 助手配置：您创建的助手及其设置（系统提示词、参数等）仅存储在设备本地。
  • 图片：您选择或拍摄的图片保存在对话记录中，并仅在发送消息时传给当前 AI API 服务商。
  • 联网工具内容：仅在您开启联网搜索后，您的问题、模型自行生成的搜索词和待读取网页地址才会发送给相应服务。搜索可能由模型服务商内置工具、Exa MCP、Tavily、Bocha、智谱或 Exa 处理；网页正文优先通过 Jina Reader 读取，失败时由您的设备直接访问目标网页。

2. 数据存储

本应用的所有数据均存储在您 iPhone 的本地文件系统中，包括：

  • API 服务商配置信息
  • AI 助手配置信息
  • 对话历史记录
  • 用户偏好设置
  • 您主动添加到对话中的图片

这些数据不会被同步到任何云端服务器。如果您删除本应用，所有本地数据将被永久删除。

3. 网络通信

本应用会与您配置的第三方 AI API 服务商进行网络通信，以实现 AI 对话功能。这些通信：

  • 仅在您主动发送消息时发生
  • 直接连接到您配置的 API 服务商（如 Anthropic、DeepSeek 等）
  • 开启联网搜索时，直接连接到您选择的搜索服务商；Exa MCP 免费版连接 Exa 的公共 MCP 服务
  • 模型调用网页读取时，会连接 Jina Reader；Jina Reader 不可用时，设备会直接连接目标网页
  • 不经过本应用的任何中间服务器
  • 通信内容受 HTTPS 加密保护

请注意，您发送给第三方 AI API 或搜索服务商的对话、图片和搜索问题受相应服务商自身的隐私政策约束。建议您查阅相关服务商的隐私政策。

4. 第三方服务

本应用不集成任何第三方分析、广告或追踪 SDK。本应用不使用 Cookie 或类似的追踪技术。

5. 儿童隐私

本应用不针对 13 岁以下的儿童。我们不会有意收集 13 岁以下儿童的个人信息。

6. 数据安全

搜索服务 API 密钥保存在 iOS 钥匙串；其他本地配置和对话数据存储在应用沙箱中，受 iOS 系统级别的安全保护。建议您：

  • 为您的 iPhone 设置密码或生物识别锁定
  • 定期更新您的 API 密钥
  • 不要在公共场合展示您的 API 配置信息

7. 隐私政策更新

本隐私政策可能会不定期更新。更新后的政策将在本页面发布，并更新顶部的“最后更新日期”。

8. 联系我们

如果您对本隐私政策有任何疑问，请通过以下方式联系我们：

邮箱：ddchatsupport@gmail.com

DDchat Privacy Policy

Last updated: August 23, 2026

DDchat (the “App”) takes your privacy seriously. This Privacy Policy explains how the App collects, uses, and protects your information.

1. Information Collection

The App does not create user accounts, display advertisements, or use analytics SDKs to collect your personal information. To provide the AI chat and web search features you choose to use, relevant content is sent directly to the third-party service provider you select:

  • API keys: The API provider addresses and keys you configure are stored only on your device and are not uploaded to any server.
  • Chat content: All conversations with AI assistants are stored only on your device.
  • Assistant configurations: Assistants you create and their settings, including system prompts and parameters, are stored only on your device.
  • Images: Images you select or capture are saved in the conversation history and are sent to the current AI API provider only when you send a message.
  • Web tool content: Only after you enable web search will your question, search terms generated by the model, and URLs to be read be sent to the relevant services. Searches may be processed by a model provider’s built-in tools, Exa MCP, Tavily, Bocha, Zhipu, or Exa. Webpage content is read through Jina Reader first; if that fails, your device accesses the target webpage directly.

2. Data Storage

All App data is stored in the local file system on your iPhone, including:

  • API provider configurations
  • AI assistant configurations
  • Chat history
  • User preferences
  • Images you add to conversations

This data is not synchronized to any cloud server. If you delete the App, all local data will be permanently deleted.

3. Network Communication

The App communicates with third-party AI API providers you configure to provide AI chat functionality. These communications:

  • Occur only when you actively send a message
  • Connect directly to your configured API provider, such as Anthropic or DeepSeek
  • Connect directly to your selected search provider when web search is enabled; the free Exa MCP option connects to Exa’s public MCP service
  • Connect to Jina Reader when the model requests webpage content; if Jina Reader is unavailable, your device connects directly to the target webpage
  • Do not pass through any intermediary server operated by the App
  • Are protected by HTTPS encryption

Please note that conversations, images, and search queries sent to third-party AI API or search providers are governed by those providers’ own privacy policies. We recommend reviewing the privacy policies of the relevant providers.

4. Third-Party Services

The App does not integrate any third-party analytics, advertising, or tracking SDKs. The App does not use cookies or similar tracking technologies.

5. Children’s Privacy

The App is not directed at children under the age of 13. We do not knowingly collect personal information from children under 13.

6. Data Security

Search service API keys are stored in the iOS Keychain. Other local configurations and chat data are stored in the App sandbox and protected by iOS system-level security. We recommend that you:

  • Protect your iPhone with a passcode or biometric lock
  • Update your API keys regularly
  • Do not display your API configuration information in public

7. Privacy Policy Updates

We may update this Privacy Policy from time to time. The updated policy will be posted on this page, and the “Last updated” date above will be revised.

8. Contact Us

If you have any questions about this Privacy Policy, please contact us at:

Email: ddchatsupport@gmail.com

1. 情報の収集

本アプリは、ユーザーアカウントの作成、広告の表示、または分析 SDK を使用した個人情報の収集を行いません。お客様が選択して利用する AI チャットおよびウェブ検索機能を提供するため、関連する内容はお客様が選択した第三者サービスプロバイダーへ直接送信されます。

  • API キー：設定した API プロバイダーのアドレスとキーはお客様の端末内にのみ保存され、いかなるサーバーにもアップロードされません。
  • チャット内容：AI アシスタントとのすべての会話履歴は、お客様の端末内にのみ保存されます。
  • アシスタント設定：作成したアシスタントとその設定（システムプロンプト、パラメータなど）は、端末内にのみ保存されます。
  • 画像：選択または撮影した画像は会話履歴に保存され、メッセージの送信時にのみ、現在の AI API プロバイダーへ送信されます。
  • ウェブツールの内容：ウェブ検索を有効にした場合に限り、お客様の質問、モデルが生成した検索語、読み取り対象のウェブページ URL が関連サービスへ送信されます。検索は、モデルプロバイダーの内蔵ツール、Exa MCP、Tavily、Bocha、Zhipu、または Exa によって処理される場合があります。ウェブページ本文はまず Jina Reader を通じて読み取られ、失敗した場合はお客様の端末から対象ページへ直接アクセスします。

2. データの保存

本アプリのすべてのデータは、お客様の iPhone のローカルファイルシステムに保存されます。これには以下が含まれます。

  • API プロバイダーの設定情報
  • AI アシスタントの設定情報
  • チャット履歴
  • ユーザー設定
  • 会話に追加した画像

これらのデータがクラウドサーバーへ同期されることはありません。本アプリを削除すると、すべてのローカルデータは完全に削除されます。

3. ネットワーク通信

本アプリは、AI チャット機能を提供するため、お客様が設定した第三者 AI API プロバイダーと通信します。これらの通信は以下のとおりです。

  • お客様がメッセージを送信した場合にのみ行われます
  • Anthropic や DeepSeek など、設定した API プロバイダーへ直接接続します
  • ウェブ検索が有効な場合、選択した検索プロバイダーへ直接接続します。Exa MCP の無料版は Exa の公開 MCP サービスへ接続します
  • モデルがウェブページの読み取りを要求した場合、Jina Reader へ接続します。Jina Reader が利用できない場合は、端末から対象ページへ直接接続します
  • 本アプリが運営する中継サーバーを経由しません
  • 通信内容は HTTPS 暗号化によって保護されます

第三者の AI API または検索プロバイダーへ送信される会話、画像、検索内容には、各プロバイダーのプライバシーポリシーが適用されます。該当するプロバイダーのプライバシーポリシーをご確認ください。

4. 第三者サービス

本アプリは、第三者の分析、広告、追跡 SDK を一切組み込んでいません。また、Cookie または類似の追跡技術を使用しません。

5. お子様のプライバシー

本アプリは 13 歳未満のお子様を対象としていません。13 歳未満のお子様の個人情報を意図的に収集することはありません。

6. データセキュリティ

検索サービスの API キーは iOS キーチェーンに保存されます。その他のローカル設定とチャットデータはアプリのサンドボックス内に保存され、iOS のシステムレベルのセキュリティによって保護されます。以下を推奨します。

  • iPhone にパスコードまたは生体認証ロックを設定する
  • API キーを定期的に更新する
  • 公共の場で API 設定情報を表示しない
